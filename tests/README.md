# Conformance tests

Golden and behavior tests for:
- ASI edge cases
- visibility
- type inference
- MI layout behavior
- using + disposal
- REPL redefinition
- module declarations and field syntax
- pipe operator (`|>`) chaining and desugaring
- `[Optim]` attribute parsing on module fields
- `dim` declarations and `Tensor[Dim1, Dim2, ...]` shape annotations
- scope-based auto-free for Tensor, Module, Optimizer
